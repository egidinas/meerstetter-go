Package Map

MeCom Core

mecom, mecomdict, and mecomserver own framing, dictionaries, and serialized downstream sharing.

CAN and CANopen

canopen, canopen/eds, objectdict, canadapter, and socketcan keep bus ownership adapter-neutral.

TM/TC Contracts

control, tmtc, sequencer, and export expose reusable command, telemetry, and export contracts.

Command Boundary

read cmd/mecomprobe

Bounded MeCom read probe for TCP or serial endpoints. It is suitable for public protocol validation and does not encode lab routes.

write cmd/mecomset

Bounded write probe for explicit operator-approved targets. Applications own lease policy, safety interlocks, and real procedure authority.

adapter cmd/teccanprobe

SocketCAN/CANopen discovery and optional local CAN ring capture. Kvaser ownership, remote bridge recovery, and product routes stay outside this module.

SignalForge Interaction

Reusable core

Meerstetter-Go consumes public SignalForge contracts for control-program and automation shape where the concepts are product-neutral.

Private boundary

Loom owns private command authority, controller ownership, lab host routing, deployment, and operator workflow composition.

Gossamer relationship

Gossamer is the public browser/demo consumer of SignalForge patterns. Meerstetter-Go remains the public MeCom/CAN protocol consumer.
